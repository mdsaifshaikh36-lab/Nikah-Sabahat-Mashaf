# Sabahat ♥ Mashaf — Islamic Wedding Invitation

Upload `index.html`, `style.css`, and `script.js` to the root of a GitHub Pages repository.

## Features
- Islamic green/cream/gold design with Arabic calligraphy, arch motifs and lantern-inspired details.
- Scratch-to-reveal Nikah date; countdown appears only after scratching.
- Mobile-friendly layout.
- Haldi, Milad-ul-Nabi ﷺ and Nikah details.
- Family, groom, venue and RSVP information.
- Google Maps button uses the supplied Maps link.
- Optional background music: add a file named `music.mp3` beside `index.html`.

GitHub Pages: Settings → Pages → Deploy from branch → choose `main` and `/root`.
